**Lingkup layanan:** (Perpustakaan Cendekia WFR berada di kampus dan melayani mahasiswa. Layanan yang tersedia meliputi keanggotaan, katalog buku, peminjaman, pengembalian, dan denda. Petugas sirkulasi mencatat data peminjaman dan pengembalian. Petugas katalog mengelola data buku dan eksemplar. Kepala perpustakaan menerima laporan bulanan tentang buku terpopuler, anggota paling aktif, dan total denda. Selama ini pencatatan dilakukan secara manual di buku besar atau spreadsheet, sehingga pencarian riwayat pinjaman satu mahasiswa menjadi lama dan rawan salah tulis. Selain itu, ketika kartu anggota hilang, petugas butuh cara lain mencari data anggota. Karena itu, perpustakaan membutuhkan basis data untuk menyimpan data buku, eksemplar, dan anggota di satu tempat yang terstruktur.)
